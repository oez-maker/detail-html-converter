TOOL 02

1688 수입 원가 계산기

1688 주문을 붙여넣고 환율·배대지·관부가세를 입력해 상품별 낱개 원가를 계산합니다.

가이드 목록원가 계산기 열기
  • 처음 사용하기주문 붙여넣기부터 계산 설정, 환율, 공통비용 입력, 결과 저장까지 전체 흐름을 순서대로 설명합니다.
  • 1688 주문 복사하기1688 주문 목록에서 어느 범위를 복사해야 계산기가 주문을 정확히 인식하는지, 인식 결과를 어떻게 확인하는지 설명합니다.
  • 환율과 결제 원화실제 결제 원화로 환율을 계산하는 방식과 환율을 직접 입력하는 방식의 차이, 어떤 값을 넣어야 하는지 설명합니다.
  • 공통비용 배분배대지 비용, 통관수수료, 관세, 부가세, 국내 착불 배송비를 어떻게 입력하고 상품별로 어떻게 나누는지 설명합니다.
  • 결과 읽기와 내보내기원가 미리보기 표의 각 열이 무엇을 뜻하는지, 원가표 복사와 엑셀(CSV) 다운로드로 결과를 보관하는 방법을 설명합니다.
