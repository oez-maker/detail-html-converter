배대지·통관·관부가세 비용 입력과 배분

최종 수정: 2026년 9월 23일 · 예상 읽기 시간 5분

여러 상품을 한 번에 들여오면 배송비와 세금이 상품마다 따로 청구되지 않고 한꺼번에 나옵니다. 계산기는 이런 공통비용을 상품별로 나눠서 각 상품의 원가에 더합니다.

1. 입력하는 비용 항목

  • 배대지 비용 — 배송대행지에 낸 해외 배송비, 검수·포장 비용 등
  • 통관수수료 — 관세사나 배대지가 청구한 통관 대행 수수료
  • 관세, 부가세 — 수입 통관 때 낸 세금
  • 국내 착불 배송비 — ‘별도 착불 배송비 발생’을 고른 경우에만 입력

모두 원화로 입력합니다. 개인 수입을 고르면 관세·부가세·통관수수료는 0원으로 바뀝니다.

2. 자동 배분: 상품금액 비례

기본값은 ‘자동 배분(상품금액 비례)’입니다. 상품대금이 전체의 30%인 상품은 각 공통비용의 30%를 가져갑니다. 원 단위로 반올림하면서 생기는 끝전은 합계가 입력한 비용과 정확히 같아지도록 조정합니다. 무게나 부피를 입력하지 않아도 되는 대신, 가볍고 비싼 상품이 배송비를 더 많이 부담하게 된다는 점을 기억해 두세요.

3. 직접 배분

부피가 큰 상품이 배송비 대부분을 차지했거나, 특정 상품에만 관세가 붙은 경우처럼 비례 배분이 현실과 다르면 해당 비용 옆의 ‘직접 배분’을 고릅니다. 현재 자동 배분 결과가 시작값으로 채워지고, 상품별 금액을 자유롭게 고칠 수 있습니다. 아래에 ‘배분 합계 / 실제 청구금액 / 차이’가 표시되니 차이가 0원이 되도록 맞추세요.

4. 중국 내 배송비 배분

판매자가 청구한 중국 내 배송비는 주문 안에서 상품별로 나뉩니다. 기본은 상품금액 비례이며, 주문 칸의 ‘중국 내 배송비 배분’에서 직접 금액을 정할 수도 있습니다.

부가세를 매입세액으로 공제받는 사업자라면 부가세를 원가에서 빼고 보는 편이 맞을 수 있습니다. 세무 처리 기준은 담당 세무사와 확인하세요.
