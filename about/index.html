OEZ Works 소개

OEZ Works는 온라인 셀러와 크리에이터가 매일 반복하는 자잘한 작업을 웹 도구로 풀어내는 1인 작업실입니다. 회원가입 없이 무료로 쓸 수 있는 도구를 만들고, 각 도구의 사용법과 한계를 가이드 문서로 함께 공개하며, 개발 과정을 블로그에 기록합니다.

운영자는 누구인가요?

안녕하세요, OEZ Works를 만들고 운영하는 오이지(OEZ)입니다. 온라인 쇼핑몰을 직접 운영하면서 상품을 여러 판매 채널에 올리는 일을 해왔고, 그 과정에서 웹 개발을 익혀 반복 작업을 자동화하는 도구를 만들기 시작했습니다.

첫 번째 도구인 상세페이지 HTML 변환기도 제 필요에서 나왔습니다. 스마트스토어에서 만든 상세페이지를 에이블리 같은 다른 채널에 올릴 때마다 편집기 전용 코드를 손으로 지우고 이미지 정렬을 다시 맞추는 일을 수십 번 반복하다가, 이 정리 과정을 자동화한 것이 시작이었습니다. 혼자 쓰기 아까워 공개했고, 지금은 같은 고민을 하는 셀러들이 쓸 수 있도록 가이드와 함께 다듬어가고 있습니다.

두 번째 공개 작업물은 경사로 지도(slopemap.kr)입니다. 지도 위에서 길의 경사(비탈) 정보를 확인할 수 있는 서비스로, 이동 경로의 오르막·내리막을 미리 살펴 더 편한 길을 고르는 데 도움을 줍니다.

세 번째로 공개한 1688 수입 원가 계산기는 중국 1688에서 상품을 들여올 때 상품대금, 배대지 비용, 관부가세를 상품별로 나눠 낱개 하나의 실제 원가를 계산하는 도구입니다. 변환기와 마찬가지로 입력한 주문 내용은 브라우저 안에서만 처리합니다.

도구 하나를 만들 때마다 실제로 써 보고 검증한 뒤 공개하는 것을 원칙으로 합니다. 제가 직접 쓰지 않는 도구는 만들지 않습니다.

이 사이트에는 무엇이 있나요?

  • 상세페이지 HTML 변환기 - 스마트스토어 상세페이지 HTML을 모바일 판매 채널용으로 정리하는 도구
  • 1688 수입 원가 계산기 - 1688 주문을 붙여넣어 상품별 실제 수입 원가를 계산하는 도구
  • 경사로 지도 (slopemap.kr) - 지도 위에서 길의 경사 정보를 확인하는 서비스
  • 가이드 - 도구별 사용법, 문제 해결 방법, 자주 묻는 질문
  • 블로그 - 도구 개발기, 업데이트 노트, 판매 채널 운영 워크플로

도구를 만드는 원칙

  • 브라우저 완결형: 사용자가 입력한 데이터는 서버로 전송하거나 저장하지 않고 브라우저 안에서만 처리합니다.
  • 무료 · 무가입: 모든 도구는 회원가입 없이 무료로 사용할 수 있습니다. 운영비는 광고 수익으로 충당합니다.
  • 한계 공개: 도구가 처리하지 못하는 요소와 알려진 제한 사항을 가이드에 명시합니다.
  • 피드백 반영: 오류 제보와 기능 제안을 이메일로 받아 개선에 반영합니다.
