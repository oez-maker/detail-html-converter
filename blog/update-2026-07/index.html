허브 홈페이지 신설

지금까지 oezworks.com에 접속하면 곧바로 변환기 페이지로 이동했습니다. 도구가 하나뿐이던 시절에는 문제가 없었지만, 가이드와 블로그가 늘어나고 다음 도구를 준비하면서 사이트의 전체 모습을 보여주는 입구가 필요해졌습니다. 이제 홈에서 OEZ Works가 어떤 곳인지, 어떤 도구가 운영 중인지, 최신 글은 무엇인지 한눈에 볼 수 있습니다.

블로그 오픈

이 글이 올라와 있는 블로그가 새로 생겼습니다. 도구 사용법은 가이드에, 개발 과정과 운영 이야기는 블로그에 쓰는 것으로 역할을 나눴습니다. 시작하는 이유를 담은 첫 글, 스마트에디터 HTML 구조를 분석한 개발기, 브라우저 완결형 설계에 대한 이야기, 멀티채널 운영 워크플로를 먼저 올렸습니다.

사용 가이드 5편 추가

기존 5편이던 변환기 가이드에 다섯 편을 더해 열 편이 되었습니다. 새로 추가된 가이드는 다음과 같습니다.

  • 쿠팡 상세페이지에 HTML 적용할 때 주의점 - 에이블리 외에 문의가 가장 많았던 채널입니다.
  • 상세페이지 이미지 호스팅과 업로드 전략 - 이미지 깨짐을 근본적으로 막는 방법입니다.
  • 모바일 상세페이지 레이아웃 기본기 - 변환 결과가 왜 600px 중앙 정렬인지 이해할 수 있습니다.
  • 인라인 스타일로 상세페이지 만들기 기초 - 변환 결과를 직접 수정하고 싶은 분들을 위한 기초 문법입니다.
  • 상세페이지 게시 전 최종 점검 체크리스트 - 게시 직전에 그대로 따라가면 되는 점검 목록입니다.

소개·개인정보처리방침·문의 페이지를 사이트 루트로 옮겨 하나씩만 두었습니다. 소개 페이지에는 운영자가 누구인지, 어떤 원칙으로 도구를 만드는지를 담았고 소셜 채널 링크도 연결했습니다. 개인정보처리방침은 쿠키 사용, 광고, 이용자 권리와 맞춤 광고 거부 방법까지 훨씬 자세하게 보강했습니다. 기존 변환기 쪽 주소로 접속하면 새 페이지로 자동 이동합니다.
