OEZ Works는 온라인 판매와 콘텐츠 제작 과정에서 마주치는 자잘하지만 성가신 반복 작업을 웹 도구로 풀어내는 1인 작업실입니다. 스마트스토어 상세페이지를 다른 판매 채널로 옮길 때마다 HTML을 손으로 고치던 경험에서 첫 번째 도구인 상세페이지 HTML 변환기가 나왔고, 지금도 실제 운영에서 부딪히는 문제를 도구로 만들어 하나씩 공개하고 있습니다.

모든 도구는 회원가입 없이 무료로 사용할 수 있고, 입력한 데이터를 서버로 보내지 않고 브라우저 안에서만 처리하는 것을 원칙으로 합니다. 도구마다 실제 사용 순서와 문제 해결 방법을 정리한 가이드를 함께 제공하며, 개발 과정과 업데이트 소식은 블로그에 기록합니다.

HOW IT WORKS

OEZ Works가 도구를 만드는 방식

실사용에서 출발

  • 운영자가 직접 겪은 반복 작업만 도구로 만듭니다.
  • 기능을 늘리기보다 한 가지 작업을 확실히 처리합니다.
  • 실제 사용 흐름을 가이드 문서로 함께 공개합니다.

데이터를 맡지 않는 설계

  • 입력한 내용은 브라우저 안에서만 처리합니다.
  • 변환 원본과 결과를 서버에 저장하지 않습니다.
  • 회원가입과 로그인 없이 바로 사용할 수 있습니다.

투명한 운영

  • 개발 과정과 한계를 블로그에 기록합니다.
  • 도구가 처리하지 못하는 부분을 가이드에 명시합니다.
  • 오류 제보와 제안은 이메일로 직접 받습니다.
