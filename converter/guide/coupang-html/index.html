쿠팡 상세페이지에 HTML 적용할 때 주의점

작성일: 2026년 6월 26일 · 예상 읽기 시간 5분

에이블리 다음으로 문의가 많았던 채널이 쿠팡입니다. 쿠팡은 상세페이지 등록 방식이 판매 방식과 카테고리에 따라 달라서, 변환한 HTML을 붙여넣기 전에 자신의 등록 화면이 어떤 방식인지부터 확인해야 합니다.

등록 방식부터 확인하세요

쿠팡 판매자 센터(WING)의 상품 등록 화면에서 상세 설명 영역은 크게 에디터 방식과 HTML 방식으로 나뉩니다. 에디터 방식은 이미지와 텍스트 블록을 화면에서 조립하는 형태라 외부 HTML을 그대로 받지 않고, HTML 작성 모드를 지원하는 화면에서만 변환 결과를 붙여넣을 수 있습니다. 같은 계정이라도 카테고리와 상품 유형에 따라 화면 구성이 다를 수 있으므로, 반드시 본인 등록 화면에서 HTML 입력이 가능한지 먼저 확인하세요.

허용되는 요소가 보수적입니다

쿠팡은 상세 설명에서 스크립트, iframe, 외부 임베드처럼 동작을 포함하는 요소를 허용하지 않는 방향으로 정책을 운영해왔습니다. 변환기의 기본 설정처럼 문단, 이미지, 인라인 스타일 중심의 단순한 HTML이 가장 안전합니다. 동영상 제거 옵션은 켠 상태로 변환하고, 동영상이 꼭 필요하다면 쿠팡이 공식 제공하는 업로드 기능이 있는지 확인해서 그쪽을 이용하세요.

이미지는 쿠팡 서버 기준으로 생각하세요

다른 쇼핑몰 서버에 있는 이미지 주소를 그대로 쓰면 표시되지 않거나, 표시되더라도 원본 쇼핑몰의 설정 변경에 따라 언제든 깨질 수 있습니다. 쿠팡은 상세 이미지 업로드 기능을 제공하므로 이미지를 내려받아 직접 업로드하고, 변환 결과의 이미지 주소를 업로드 후 발급된 주소로 교체하는 것이 원칙입니다. 이미지 폭은 모바일 앱 화면을 기준으로 확인하세요. 쿠팡 구매의 대부분이 모바일에서 일어나기 때문에 PC 화면만 보고 판단하면 안 됩니다.

변환 옵션 추천값

  • 동영상 제거: 켬 (외부 임베드는 허용되지 않는다고 전제)
  • 본문 글씨 크기: 15~16px (모바일 가독성 기준)
  • 두 사진 너비: 48% 기본, 좁게 보이면 46%

자주 생기는 문제

첫째, 붙여넣은 직후에는 정상인데 저장 후 일부 스타일이 사라지는 경우가 있습니다. 플랫폼이 저장 시점에 허용하지 않는 속성을 걸러내기 때문으로, 남은 결과가 읽기에 문제없는지 모바일 미리보기로 확인하세요. 둘째, 타사 플랫폼 로고나 문구가 남아 있으면 심사에서 문제가 될 수 있습니다. 스마트스토어 전용 이벤트 문구, 네이버 관련 배지 이미지는 변환 후 반드시 삭제하세요. 셋째, 가격·배송·인증 정보는 상세페이지 본문이 아니라 쿠팡의 입력 항목이 우선합니다. 본문과 입력 항목이 어긋나면 구매자 혼란과 분쟁의 원인이 됩니다.

쿠팡의 등록 화면 구성과 허용 정책은 예고 없이 바뀔 수 있습니다. 이 가이드는 일반적인 주의점을 정리한 것이므로, 실제 등록 시에는 판매자 센터의 최신 안내를 함께 확인하세요.
