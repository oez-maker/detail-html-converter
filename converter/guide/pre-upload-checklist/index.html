상세페이지 게시 전 최종 점검 체크리스트

작성일: 2026년 7월 14일 · 예상 읽기 시간 5분

변환과 수정을 마치고 게시 버튼을 누르기 직전, 이 목록을 위에서부터 순서대로 확인하세요. 게시 후에 발견하는 문제의 대부분은 이 목록 안에 있습니다.

1. 콘텐츠 확인

  • 문단 순서가 원본과 같고, 중간에 빠진 문단이 없는지 확인했습니다. 변환 완료 문구의 컴포넌트·이미지 개수가 원본과 크게 다르지 않은지 봅니다.
  • 타사 플랫폼의 이름, 로고, 이벤트 문구(예: 스마트스토어 전용 쿠폰 안내)가 남아 있지 않습니다.
  • 동영상을 제거했다면, 동영상을 전제로 한 안내 문구("아래 영상을 참고하세요" 등)도 함께 지웠습니다.
  • 오탈자와 깨진 특수문자가 없는지 훑어봤습니다.

2. 이미지 확인

  • 모든 이미지가 미리보기에서 실제로 표시됩니다. 한 장이라도 깨져 있다면 이미지 오류 가이드로 원인을 확인하세요.
  • 주력 상품이라면 이미지를 채널에 직접 업로드하고 주소를 교체했습니다(호스팅 전략 가이드 참고).
  • 이미지 사용 권한을 확인했습니다. 사입처·제조사 이미지는 사용 허락 범위 안에 있습니다.
  • 이미지 속 텍스트가 휴대폰 화면에서 읽히는 크기입니다.

3. 상품 정보 확인

  • 상세페이지 본문의 가격·할인 문구가 채널 입력 항목의 실제 판매가와 일치합니다.
  • 배송비, 배송 기간, 교환·반품 안내가 이 채널의 실제 정책과 일치합니다. 다른 채널 기준의 문구가 남아 있으면 분쟁의 원인이 됩니다.
  • 인증 정보(KC 인증 등), 원산지, 소재·성분 표기가 채널의 필수 입력 항목과 어긋나지 않습니다.
  • 재고와 옵션 구성이 본문 설명과 일치합니다.

4. 모바일 미리보기 확인

  • 채널의 모바일 미리보기(또는 실제 휴대폰)에서 가로 스크롤이 생기지 않습니다.
  • 나란한 이미지 두 장이 잘리거나 겹치지 않습니다. 문제가 있으면 변환기에서 두 사진 너비를 46~47%로 낮춰 다시 변환하세요.
  • 본문 글자가 확대 없이 읽히는 크기입니다.
  • 문단 사이 간격이 답답하거나 지나치게 벌어진 곳이 없습니다.

5. 게시 후 확인

게시가 끝나도 한 가지가 남습니다. 실제 상품 페이지를 구매자 입장에서 한 번 열어보는 것입니다. 미리보기와 실제 게시 화면이 다르게 렌더링되는 채널이 있고, 저장 과정에서 일부 스타일이 걸러지기도 합니다. 특히 첫 게시라면 하루 이틀 뒤 이미지가 여전히 정상 표시되는지 다시 확인하세요. 외부 이미지 차단은 게시 직후가 아니라 뒤늦게 나타나는 경우가 많습니다.

이 체크리스트는 기술적 점검 항목이며, 채널별 심사 기준과 광고·표시 관련 법규 준수를 대신하지 않습니다. 채널의 최신 등록 가이드와 함께 사용하세요.
